# Finantech - Project Overview

## 📋 Project Description

**Backend API** for a banking system that manages user accounts, transfers, and real-time notifications. Built with **Java 17** and **Spring Boot 3.x** to demonstrate mid-level backend development skills for the Colombian job market.

**Domain:** Financial Services / Banking  
**Type:** RESTful API with event-driven architecture  
**Target Role:** Mid-Level / Senior Junior Java Developer

---

## 🎯 What We're Trying to Achieve

### Technical Goals
- Build a production-ready API with clean, maintainable code
- Implement JWT authentication and role-based security
- Create event-driven notifications using Apache Kafka
- Achieve 70%+ test coverage with JUnit and Mockito
- Containerize with Docker for easy deployment
- Document all endpoints with OpenAPI/Swagger

### Career Goals
- Demonstrate skills required for mid-level Java positions in Colombia
- Show understanding of microservices and distributed systems
- Build a portfolio piece that stands out from basic CRUD apps
- Increase interview callbacks by 50%+
- Qualify for positions with 20-40% salary increase
